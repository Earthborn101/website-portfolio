# Ryan Adiao — Portfolio

Personal portfolio site for **Ryan Christopher D. Adiao**, Senior Software Engineer specializing in Elixir, Phoenix, and distributed systems.

## Stack

- Vite
- React 19
- TypeScript
- Tailwind CSS v4

## Local development

```bash
npm install
npm run dev
```

The dev server binds to **http://127.0.0.1:4321**.

## Build

```bash
npm run build
npm run preview
```

## Content

Copy for experience, skills, education, and contact details lives in `src/content.ts` and is sourced from the resume content provided for this project.
